# badge437

Repo path: `steanlab/badge437` (public).

Own firmware and a web control page for the **Hanshow Nebular Pro 437Q-N**: a 4.37" electronic shelf label with a 480 x 176 black / white / red / yellow e-paper panel and a Telink Bluetooth LE chip.

> **Status (November 2026): work has just started, there is no firmware and no page yet.** This repository is a placeholder. Nothing here can be flashed.

## Plan

- A control page (Web Bluetooth, Chrome or Edge) for sending pictures to the tag and changing settings, like the one for the 970Q-N.
- A released firmware binary with its checksum and a flashing guide. Flashing replaces the original firmware, so a backup of your own tag's stock flash will be required.
- A user guide in English and Russian.

The same author's finished project for the bigger tag: [frame970](https://github.com/steanlab/frame970). For the smaller one: [badge154](https://github.com/steanlab/badge154).

## What will and will not be published here

The page, the released firmware, the guides and hardware notes that are safe to publish. **Not** published: flash dumps, panel waveform tables, serial numbers and addresses of tags, the firmware source code and the analysis of the original firmware.
